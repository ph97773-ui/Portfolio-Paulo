# Portfólio Pessoal — Paulo Henrique L. Rodrigues

## Descrição

Este projeto é meu portfólio pessoal, criado para apresentar um pouco do meu perfil, meus projetos de estudo e as tecnologias que estou aprendendo no curso de Desenvolvimento de Sistemas.

O site possui as seções Perfil, Projetos, Habilidades e Contato. O menu no topo leva para cada parte da página.

## Tecnologias utilizadas

- HTML5;
- CSS3;
- JavaScript;
- Bootstrap 5.3;
- GitHub Pages.

## Link do site publicado

Depois de ativar o GitHub Pages, inserir aqui o endereço:

`https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/`

## Funcionamento do projeto

A página principal está no arquivo `index.html`. O Bootstrap é carregado por CDN e ajuda na organização do menu, das colunas, dos botões e da responsividade.

O arquivo `style.css` contém a personalização visual do portfólio, como cores, espaçamentos, cartões e efeitos de hover. O arquivo `script.js` controla a mensagem interativa da seção de recurso novo.

O menu utiliza links para âncoras, como `#perfil`, `#projetos`, `#habilidades` e `#contato`. Assim, ao clicar em uma opção, a página vai até a seção correspondente.

## Recurso novo adicionado

Além das seções básicas, foi incluída uma área de Habilidades com barras de progresso e uma interação em JavaScript: o botão “Mostrar mensagem”.

Também foram adicionadas animações de hover nos cartões dos projetos. Quando o mouse passa sobre um cartão, ele se move levemente para cima e recebe uma sombra. Isso deixa a navegação mais agradável.

O botão interativo foi implementado no arquivo `script.js`. Ao clicar nele, a mensagem aparece ou desaparece e o texto do botão também muda.
